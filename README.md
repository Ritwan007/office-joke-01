# The Funniest Office Joke — entry

One line: the funniest joke about office life. Entry for the make.fun
competition `u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c` —
see https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c

## The line

> The meeting that could have been an email is over — it ended with an email summarising the meeting that could have been an email.

## How it works

`main.py` (Python 3, no dependencies) validates the line against the
competition gate — UTF-8 text, 1–200 characters, a single line, not only
whitespace — writes it, with no trailing newline, to `/output/entry.txt`,
then reads the file back and confirms it is byte-exact the chosen line.

```sh
python3 main.py
```
